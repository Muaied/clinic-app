# نظام إدارة العيادات الطبية الشامل (Clinic Management System)

نظام إدارة متكامل للعيادات الطبية، تم بناؤه باستخدام (React, Vite, Node.js, Express, MySQL) ويدعم اللغة العربية والتخطيط من اليمين لليسار (RTL) بشكل أساسي.

## 🚀 نظرة عامة
تم تصميم هذا النظام ليكون مشروع تخرج احترافي أو مشروع بورتفوليو لـ Full Stack Developer. يوفر النظام لوحة تحكم عصرية وواجهة مستخدم احترافية بالكامل.

### الميزات الأساسية:
- نظام صلاحيات للمستخدمين (Admin, Doctor, Receptionist).
- لوحة تحكم ذكية (Dashboard) مع رسوم بيانية لإحصائيات العيادة.
- إدارة كاملة للمرضى (CRUD).
- إدارة كاملة للأطباء.
- إدارة وحجز المواعيد.
- إدارة السجلات والوصفات الطبية.
- نظام فواتير مبسط وتتبع المدفوعات.

## 🛠 التقنيات المستخدمة

**الواجهة الأمامية (Frontend):**
- React.js مع Vite
- React Router DOM
- Tailwind CSS (RTL & Dark Mode/Neon theme)
- Axios & Recharts & Lucide-React

**الواجهة الخلفية (Backend):**
- Node.js & Express.js
- MySQL2 (Parameterized queries)
- JWT Authentication
- bcrypt (Password hashing)
- dotenv

## 📦 كيفية إعداد المشروع للعمل

### 1. إعداد قاعدة البيانات (MySQL)
1. قم بإنشاء قاعدة بيانات باسم `clinic_management`.
2. قم باستيراد ملف `database_schema.sql` (الموجود في المجلد `server/database`) إلى قاعدة البيانات لبناء جميع الجداول والعلاقات.
3. يمكنك إضافة مدير نظام بشكل افتراضي عن طريق إرسال طلب `POST` إلى `http://localhost:5000/api/auth/setup-admin` بعد تشغيل الـ Backend.

### 2. إعداد وتشغيل الواجهة الخلفية (Backend)
1. افتح مجلد `server`.
2. انسخ ملف `.env.example` إلى ملف جديد وسمّه `.env`، وأدخل بيانات الاتصال الخاصة بك بقاعدة البيانات وكلمة سر `JWT_SECRET`.
3. قم بتشغيل الأوامر التالية:
```bash
npm install
npm start
```
(سيعمل السيرفر على البورت 5000).

### 3. إعداد وتشغيل الواجهة الأمامية (Frontend)
1. افتح مجلد `frontend`.
2. قم بتشغيل الأوامر التالية:
```bash
npm install
npm run dev
```
(ستعمل الواجهة الأمامية عادةً على `http://localhost:5173`).

## 🔐 بيانات تسجيل الدخول الافتراضية
يمكنك استخدام البيانات التالية إذا قمت بإنشاء الأدمن باستخدام مسار الـ `setup-admin`:
- **البريد الإلكتروني:** `admin@clinic.com`
- **كلمة المرور:** `admin123`

## 📁 هيكلية المشروع

يحتوي المشروع على المجلدات التالية:
- `server/`: يحتوي على الكود المصدري للواجهة الخلفية (Node/Express).
- `frontend/`: يحتوي على الكود المصدري للواجهة الأمامية (React/Vite).
